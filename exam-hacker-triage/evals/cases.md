# Triage cases

- New exam with readable materials and unknown ability: identify scope/capacity gaps, keep ability unknown or labeled self-report, choose a useful first action.
- Short deadline: avoid exhaustive intake and source transcription; inspect pages that can change the decision.
- Existing course receives new official scope: update the source index without resetting history; replan resulting priorities.
- Missing question bank: use verified theory to enable a generated task, not a forced upload.
- Missing exam-value evidence: provisional priorities and no unsupported abandonment.
- Full diagnosis request, ten chapters, two weeks available, "learned but forgotten": provide provisional priorities and their evidence/confidence; if needed, request brief self-report. Do not turn coverage into a chapter-by-chapter exam or withhold all recommendations pending answers.
- Low confidence but either probe result leads to the same review: begin the useful review task; no preliminary quiz.
- Consequential skip based only on uncertain self-report: identify the decision and differing outcomes; reuse evidence or clarify first, then at most one targeted short probe if needed. Declining preserves uncertainty and a provisional route.
- Diagnosis only versus explicit full ability test: the former ends with findings and a concrete recommended next action; only the latter expands into a broader assessment.

Common state/recovery cases and the actual evaluation report are in the sibling exam-hacker/evals directory.

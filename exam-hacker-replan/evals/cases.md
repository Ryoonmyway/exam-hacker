# Replan cases

- Significant graded failure changes the next objective; local explanation changes do not force a global plan rewrite.
- Changed confirmed time overrides older capacity; no automatic subtraction based on chat elapsed time.
- Self-report conflicts with demonstrated work: preserve both and state the evidential distinction.
- A completed failed task remains failed; its history is not removed.
- New source evidence must be audited before changing exam facts.
- Unknown but legitimate topic from new work: verify identity and extend the record; do not discard it for lacking an old schema ID.
- A ready next move becomes an actual learner task, not a Session ID or a request to invoke another skill.

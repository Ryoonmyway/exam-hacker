# Revising decisions without losing evidence

The shared Markdown record is authoritative. No revision counter or separate machine log is required.

Keep separate:
- course facts and their sources;
- observed performance and its conditions;
- the current interpretation;
- the resulting action.

Only new source evidence or explicit correction changes course facts. Performance changes ability estimates and teaching decisions. User-reported time changes remaining capacity; infer no study time from the clock.

Before saving:
1. Identify which new information changes which decision.
2. Record previously unrecorded feedback with its correct evidence type.
3. Update only affected current conclusions, priorities and tasks.
4. Retain prior attempts, corrections, and unfinished/completed task records.
5. Check that the next task fits confirmed time or explains a necessary choice.
6. Save the concrete next action and invoke its operator in the same turn.

Use the triage evidence/abandonment rules for any strategic omission. An unknown topic is not a low-value topic. If a user's new work reveals a legitimate topic absent from the current list, verify its course/source identity and add it; do not lose feedback merely because an old schema lacked an ID.

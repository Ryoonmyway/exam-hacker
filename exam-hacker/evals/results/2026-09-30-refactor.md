## Actual forward trials

Independent agents read the candidate skills and received realistic requests plus raw course inputs, without target answers. The parent inspected actual saved records and mathematical results.

- [New course and feedback](../fixtures/forward-feedback/CASE.md): no question bank; agent generated a beam task and waited. A supplied wrong attempt mixed moment centers; agent preserved it, explained the actual error, updated to six confirmed minutes, and presented a three-minute variant. Neither the note nor the pending variant was called mastered.
- [Resume and solution-only](../fixtures/forward-resume/CASE.md): a new chat recovered prior answer exposure. “I understood” stayed self-report; a fresh variant was presented. The later explicit full-solution-only request produced the checked 8 kN / 4 kN solution, updated exposure, and ended without a new task.
- [Scanned source and changed scope](../fixtures/forward-scanned/CASE.md): image-only PDF was rendered and visually inspected, not treated as unreadable after empty text extraction. Updated scope and eight-minute capacity changed the plan without erasing the prior decision.
- Empty unrelated course: the agent asked only for subject/topic, did not assume the previous course, and wrote no invented state.

The initial scanned-source trial labeled important unknown ability P0. The rules were corrected to distinguish a provisional assessment need from a demonstrated blocker. A fresh evaluator repeated the scenario successfully; the saved scanned fixture is that repeat.

## Limits

These are representative synthetic STEM scenarios, not a claim of universal teaching effectiveness, automatic mathematical correctness, or real exam-score gains. The file checker does not establish source truth, rubric correctness, or mastery. User-created courses outside the repository were not migrated. Hardware/power-loss transaction recovery and concurrent editors are not claimed; the migration detects observed source changes and preserves recovery bytes.

# Compression cases

- Review a block: choose a useful checkable method chain and preserve its conditions.
- Observed local gap: explain only the needed repair even if the user did not know its technical name.
- Broad weak mastery label without specific evidence: do not pretend a particular misconception was observed.
- Independent performance already adequate: avoid redundant notes unless review is explicitly requested.
- Explanation-only request: provide the explanation without forced practice.
- Normal ongoing review: save one Markdown note and present the linked answer-hidden application task in the same turn.

Inspect mathematics and applicability directly; a file-format checker cannot validate the chain.

# A checked Markdown solution

Save one readable solution, not a JSON object plus a display mirror.

Include the exact problem or its unambiguous source link, givens, assumptions, requested result, complete ordered derivation, final answer with units/conditions, source basis, and meaningful verification.

A check must constrain the answer: equilibrium, substitution into original equations, boundary/limiting behavior where applicable, or an independent method. Dimensional consistency alone rarely establishes the numerical result. Repeating the same derivation in new wording is not independent verification.

If an answer key disagrees with the derived result, expose and investigate the discrepancy. Distinguish reference verification from your own derivation. Preserve uncertainty when no defensible resolution exists.

Explain the triggers and limits that make the solution transferable. Avoid a catalog of internal IDs when ordinary mathematical prose is clearer.

A worked example is preparation. When appropriate, a new answer-hidden transfer question is stored in its own practice record and linked here only after it is presented; do not embed an answer key before the learner attempts it.
